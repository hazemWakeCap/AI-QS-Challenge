# Feature 4 — QS Copilot

## What it is

A plain-English assistant over the project's data. You ask a question; the copilot calls
read-only analytics **tools** that do the computation, the language model narrates the result,
and the response returns the tool-call evidence alongside the answer for auditing. It doubles
as the natural front-end to the whole suite — watchlist, forecast, variance, and stress-test —
behind one conversational interface.

## Who it's for

Any QS who'd rather ask *"which packages are dragging our CPI down this month?"* than click
through tabs.

## How it works

- **Tools compute, the model narrates.** All arithmetic on AED figures lives in the tools; the
  model is instructed not to do the math itself but to call a tool and narrate the result. This
  is enforced by tool design plus system-prompt instructions — the response returns the
  tool-call evidence so any figure can be traced back to its source. (It is a strong design
  guarantee, not a hard proof that every narrated digit was individually cited.)
- **Authorization happens before the LLM runs.** The RLS-scoped project snapshot is resolved
  first (returning `401/403/404` as appropriate); the per-request tools are built from that
  snapshot, so a non-member never reaches a tool call.
- Every tool reads the **same project snapshot** the dashboard/forecast/stress-test serve, so
  the copilot can never disagree with the rest of the app.

### Available tools

| Tool | Returns |
|------|---------|
| `GetWatchlist` | Ranked GREEN-about-to-tip centres (Feature 1). |
| `GetCostCentreDetail` | EVM detail for one cost centre. |
| `ExplainDrift` | Why a centre is drifting. |
| `GetEvmSnapshot` | EVM snapshot for a period. |
| `ForecastIncrementalSpend` | Validated next-period spend (Feature 2). |
| `DirectionalEac` | Directional final-cost estimate (labelled directional). |
| `ResourceSplit` | Resource-category breakdown. |
| `ProjectEvm` | Project-level EVM (`sum(EV)/sum(AC)`, never a mean of CPIs). |
| `StressFlagsForPackage` | Estimate stress flags for a package (Feature 3). |
| `ExplainVariance` | Variance attribution for a package/period (Feature 5). |

## API

| Endpoint | Purpose |
|----------|---------|
| `POST /api/v1/copilot/ask` | Ask a question; returns a narrated, tool-cited answer. `400` on malformed input. |

## UI

The **Model & Copilot** tab (`Copilot`), alongside the validation panel.

## Guarantees & limits

- **Math lives in the tools** — figures are tool-computed and the response ships the tool-call
  evidence for auditing, rather than being free-generated by the model.
- **Project CPI is aggregated correctly** — `sum(EV)/sum(AC)`, never the mean of per-row CPIs.
- Answer quality depends on the underlying tools; the copilot inherits each feature's own
  validated-vs-directional boundaries.
